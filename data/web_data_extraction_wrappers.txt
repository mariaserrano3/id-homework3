Web data extraction is the task of obtaining structured data from web pages. A wrapper is a program that extracts the values of the attributes of interest from the pages of a website.

Wrappers are often written with XPath or CSS selectors, which identify the nodes of the HTML tree that contain the data. Pages generated by the same template share the same structure, so one wrapper can process thousands of pages.

Wrappers break when the site changes its layout. Wrapper induction techniques learn the rules automatically from a few annotated pages, and they can be combined with active learning to reduce the annotation effort.
